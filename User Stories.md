User Stories



**Epic 1 — Account \& Identity**



US-01

As a user, I want to create an account so that I can participate in the platform.



US-02

As a user, I want to maintain a profile containing relevant information about myself so that other participants can make an informed decision about interacting with me.



**Epic 2 — Peer-to-Peer Tasks**



US-03

As a requester, I want to create a task describing the help I need so that contributors can offer to complete it.



US-04

As a contributor, I want to browse available tasks so that I can find tasks relevant to me.



US-05

As a contributor, I want to submit an offer for a task so that the requester can choose me to perform it.



US-06

As a requester, I want to select a contributor from the received offers so that the task can be assigned.



US-07

As a requester and contributor, I want to mark the task as completed so that the transaction can be finalized.



US-08

As a user, I want to review another participant after a completed task so that future users can evaluate their reputation.



US-09

As a user, I want to see another user's reputation so that I can evaluate whether I trust them.



**Epic 3 — Social Impact Activities**



US-10

As an organization, I want to create volunteer activities so that contributors can discover ways to support our cause.



US-11

As an organization, I want to see who has registered for my activity so that I can manage participation.



US-12

As a contributor, I want to browse available volunteer activities so that I can find opportunities that match my interests and availability.



US-13

As a contributor, I want to register for a volunteer activity so that the organization knows that I intend to participate.



US-14

As an organization, I want to verify that a contributor has completed an activity so that Karma Koin are only awarded for legitimate contributions.



**Epic 4 — Karma Koin**



US-15

As a contributor, I want to receive Karma Koin after a verified activity so that my social contributions are recognized.



US-16

As a user, I want to see my current Karma Koin balance so that I know how many points I can spend.



US-17

As a user, I want to see my Karma Koin transaction history so that I can understand how my balance has changed.



US-18

As the platform, I want every Karma Koin transaction to be traceable to its origin so that the reward system can be audited.



**Epic 5 — Rewards**



US-19

As a reward partner, I want to create rewards so that contributors can redeem their Karma Koin at my business.



US-20

As a user, I want to browse available rewards so that I can decide how to spend my Karma Koin.



US-21

As a user, I want to redeem Karma Koin for a reward so that I receive a benefit for my contribution.



US-22

As a reward partner, I want to see statistics for a given reward so that I can track how popular rewards are compared to each other.



**Epic 6 — Trust \& Safety**



US-23

As the platform, I want restricted actions to require the appropriate role so that users cannot perform actions for which they are not authorized.



US-24

As an administrator, I want to inspect disputed or suspicious activities and transactions so that misuse of the platform can be investigated
